# Source evaluation

Use this reference for version-sensitive evidence, historical attribution or priority, conflicting sources, and absence claims.

## Separate source roles

- Publisher, DOI, arXiv, repository, and bibliographic records establish identity, dates, publication state, corrections, retractions, and version relationships.
- The paper, supplement, data, or code containing the result establishes substantive support.
- Preserve a historical or version-specific source when the question concerns what was known, implemented, or stated at that time. The newest version is not automatically the controlling one.

## Resolve disagreement

Compare the proposition actually measured or derived, definitions, assumptions, method, sample or system, parameter regime, uncertainty, and version. Do not treat two papers as corroborating or conflicting until those predicates overlap.

Cross-check when another independent source can resolve a live uncertainty. Do not require multiple sources when one controlling primary source settles the claim, and do not use repeated citations as a vote.

## Bound absence and priority claims

A failed search shows only that no qualifying work was found within the inspected databases, query families, date range, languages, fields, and source types. Report those boundaries rather than claiming that no work exists.

For novelty or priority, distinguish first public disclosure, preprint, conference version, accepted manuscript, and journal publication. State the convention being used and preserve unresolved near-simultaneous or version-dependent cases.
